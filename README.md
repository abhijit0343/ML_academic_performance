# ?? Student Exam Performance Predictor

An end-to-end Machine Learning web application that predicts a student's **Math score** based on demographic and academic background features. Built using a modular ML pipeline with Flask as the web interface.

---

## ?? Problem Statement

Given information about a student � such as gender, race/ethnicity, parental education level, lunch type, test preparation status, and reading/writing scores � predict their **math score** using a trained regression model.

## ?? Preprocessing Pipeline

Built using `sklearn.pipeline.Pipeline` + `ColumnTransformer`:

**Numerical columns** (`reading_score`, `writing_score`):
1. `SimpleImputer` (strategy: `median`)
2. `StandardScaler`

**Categorical columns** (`gender`, `race_ethnicity`, `parental_level_of_education`, `lunch`, `test_preparation_course`):
1. `SimpleImputer` (strategy: `most_frequent`)
2. `OneHotEncoder`
3. `StandardScaler` (with_mean=False)

## ?? Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/abhijit0343/ML_academic_performance
cd mlproject-main
```

### 2. Create a Virtual Environment
```bash
python -m venv .venv
.venv\Scripts\activate       # Windows
source .venv/bin/activate    # macOS/Linux
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the Model (generates artifacts/)
```bash
python -m src.components.data_ingestion
```

### 5. Run the Flask App
```bash
python app.py
```

### 6. Open in Browser
Navigate to: **http://localhost:5000/predictdata**

Fill out the student information form and click **"Predict your Maths Score"** to see the result.
